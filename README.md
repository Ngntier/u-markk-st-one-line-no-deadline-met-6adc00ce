A single-line joke giving an excuse for missing a deadline, written by
`main.py` to `entry.txt` for the
[One Line, No Deadline Met](https://make.fun/competitions/u-markk-st-one-line-no-deadline-met-6adc00ce)
competition on [make.fun](https://make.fun).

Referral code: [t1h9wdbp](https://make.fun/?ref=t1h9wdbp)

## Run

```sh
python3 main.py
```

Writes one line (121 characters) to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), guarded to
1–200 characters and 1–200 UTF-8 bytes, a single line, non-blank.
